# 최근 고점 대비 낙폭이 작은 암호화폐 종목 발굴

## 요구 사항

### 대상 거래소
- 업비트와 바이낸스 두 거래소를 모두 조회한다.
- 업비트는 KRW 마켓, 바이낸스는 USDT 현물 마켓을 기준으로 한다.
- 데이터는 서버를 거치지 않고 브라우저에서 거래소 공개 API로 직접 가져온다.

### 대상 종목
- 시가총액 순위는 CoinGecko에서 가져온다.
- CoinGecko에서 시가총액 상위 200개 종목을 가져온 뒤, 이 중에서 시가총액을 주기적으로 다시 계산해 상위 100위 이내 종목만 보여준다.
- 스테이블코인은 제외한다.

### 고점과 낙폭
- 고점은 5분봉 종가의 288기간 단순이동평균(SMA, 24시간)이 조회 기간 안에서 기록한 최댓값으로 한다.
- 낙폭은 `(고점 - 현재가) / 고점`으로 계산한다.
- 고점 대비 낙폭이 작은 순으로 종목을 정렬해 보여준다.

### 조회 기간
- 조회 기간(최근 N일)을 지정할 수 있다. 기본값은 1개월(30일)이다.
- 1개월, 2개월, 3개월, 4개월, 6개월 버튼으로 조회 기간을 선택할 수도 있다.

## 배포
- GitHub Pages로 배포한다.
- 정적 파일은 `site/` 디렉터리에 둔다.
- `main` 브랜치의 `site/`가 바뀌면 GitHub Actions 워크플로([.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml))가 자동으로 배포한다.
